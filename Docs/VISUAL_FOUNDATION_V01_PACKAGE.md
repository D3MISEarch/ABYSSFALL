# Visual Foundation v0.1 Package Contract

The exact-head CI artifact must be named `AbyssFall-Visual-Foundation-v01-<short-sha>` and contain:

- `AbyssFall.exe`
- `AbyssFall.pck`
- `BUILD_INFO.txt`
- `PLAY_VISUAL_FOUNDATION.cmd`
- `README_VISUAL_FOUNDATION.txt`
- `SHA256SUMS.txt`

The launcher must enter the real Voidbringer route with `-- --class=void_warlock`.
